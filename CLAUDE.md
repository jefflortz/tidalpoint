# Tidal Point Partners Claude Instructions

This project is Tidal Point Partners, a premium strategic advisory firm for privately held businesses at pivotal moments.

Preserve the existing architecture and Tailwind Studio design system unless explicitly asked to change them.

Do not introduce obvious nautical visuals such as anchors, sailboats, waves, ropes, or lighthouses.

The brand should feel professional, local, warm, practical, quietly premium, and trusted.

Do not make file changes without first explaining the implementation plan.
